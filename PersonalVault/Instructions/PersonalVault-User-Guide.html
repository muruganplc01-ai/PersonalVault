Personal Vault user guide

A walkthrough of the app itself — first run, adding accounts, the Overview tab, and Profile — using real screenshots of the actual running app.

🧪 Every screenshot on this page shows a throwaway demo vault seeded with obviously fake data ("Example Bank", demo_user, a made-up card number) — never a real vault. It exists only to illustrate the screens; nothing shown here is anyone's real account information.
1
First launch

Choose your master secret

The very first thing the app asks for. There is no password reset — this is the one key everything else is built on, so the requirements shown on screen (12+ characters, upper/lower/symbol) are enforced before it lets you continue.

Create Your Master Secret
2
Main window

An empty vault, ready to go

The Accounts tab is where everything lives day to day — search, filter by category or owner, and the Add Account button that starts every entry below. The title bar always shows whether Google Drive is connected.

Main window — nothing added yet
3
Add Account

A simple entry: name, username, password, website

Most entries — a website login, a subscription, a utility account — just need the top handful of fields. Category defaults to "Other" if nothing more specific fits; a custom category can be typed in on the spot via + New....

Account Details — a generic entry
Back at the main window after saving
4
BankAccount category

One bank, several sub-accounts

Picking the BankAccount category reveals a Checking, Savings, etc... button — this is how one entry (say, "Example Bank") holds several real sub-accounts (Checking, Savings, Money Market...), each with its own account/routing number and balance. Every sub-account's balance rolls up into the Overview tab's totals automatically.

Adding a sub-account
Checking + Savings under one bank
Account Details — BankAccount category
5
CreditCard category

A structured card details popup

The CreditCard category adds an Enter Card Details... button — a proper card number field, month/year expiration dropdowns, security code, and cardholder name, instead of typing "key=value" lines by hand. On save, the card number lands in the same Account # field every other entry uses.

Card Details popup
Account Details — CreditCard category
6
All three entries

The Accounts list, filled in

A generic login, a bank with two sub-accounts, and a credit card — three different categories, each showing the fields relevant to it.

Accounts tab with all three entries
7
Overview tab

Every balance, rolled up in one place

Anything with a tracked balance — a bank sub-account, an investment account, any category at all — shows up on the Overview tab with a running total, so "how much do I actually have on hand" doesn't require adding it up by hand.

📸 Not pictured here — this page's own screenshot automation crashed the demo app while trying to switch tabs and wasn't worth a third relaunch. The tab itself works exactly like the Accounts tab shown above, just with a Balance and As Of column instead.
