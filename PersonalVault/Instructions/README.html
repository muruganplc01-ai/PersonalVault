Personal Vault — road map

This folder has everything you need: the app, and every guide you might want. Nothing here is time-sensitive or one-shot — read this once, then come back to any step whenever you actually need it. Steps 1–3 are all you need to start using the app today. Everything after that is optional.

1
This Drive folder

Download everything to your PC

Select all the files in this folder → Download (Drive zips them for you automatically) → unzip anywhere on your PC. No installer, no admin rights needed — PersonalVault.exe runs straight from wherever you put it.

2
Double-click PersonalVault.exe

Create your own vault

Choose your own master secret (12+ characters, with uppercase, lowercase, and a symbol) and add your first account. This is yours alone — nobody, including whoever shared this folder with you, ever sees it or can reset it for you.

✓ Your data lives in a new PersonalVault folder created automatically right next to your copy of the .exe — fully portable, and completely separate from whoever shared this folder with you.
3
Read this next

Learn the everyday screens

PersonalVault-User-Guide.html covers adding/editing accounts, categories and Sub Category, the Owner dropdown, Field Sets (customizing which fields show per category), and the Profile screen's settings. This is the one doc worth reading end to end before anything else.

4
Only if you want it optional

Set up your own Google Drive backup

Follow PersonalVault-Drive-Setup-Guide.html start to finish — your own Google Cloud project, your own credentials.json, your own Drive files. About 10 minutes, entirely self-service. Skip this if you're happy keeping everything local; the app works fully offline either way.

5
Only if you want it optional

Set up one-time Share links

This is the Share... button that hands someone a real one-time link to a single password. Follow PersonalVault-Share-Setup-Guide.html — it walks through creating your own GitHub Pages site and your own Google Apps Script deployment, about 15 minutes.

ShareScript-index.html and ShareScript-Code.gs are the exact two code blocks that guide has you paste in — having them as real files means copy-pasting from a working file instead of retyping out of the guide's code boxes.

6
If you're curious optional

See exactly how it all works

PersonalVault-Security-Deep-Dive.html — the encryption scheme, the full one-time-share-link flow, and exactly why a public GitHub Pages page is safe. Not required reading, but everything in the app is explained there in full technical detail if you ever want to check.
